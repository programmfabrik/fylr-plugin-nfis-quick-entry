# nfis-quick-entry
Root-App plugin for fylr providing a simplified UI to create datasets in NFIS.
The plugin provides a new form based interface to create datasets with the Objekt, Maßnahme, and Fläche object types.


## installation

The latest version of this plugin can be found [here](https://github.com/programmfabrik/fylr-plugin-nfis-quick-entry/releases/latest/download/nfisQuickEntry.zip).

The ZIP can be downloaded and installed using the plugin manager, or used directly (recommended).

Github has an overview page to get a list of [all release](https://github.com/programmfabrik/fylr-plugin-nfis-quick-entry/releases/).
